# Meal Tracker - Daily Calorie Calculator

A web-based application for tracking daily meals and calculating calories. Built with vanilla HTML, CSS, and JavaScript.

## Features

- **Meal Tracking**: Log foods for Breakfast, Lunch, Dinner, and Snacks
- **Calorie Calculation**: Automatic calorie counting based on serving sizes
- **Food Database**: 85+ pre-loaded foods with nutritional information
- **Custom Foods**: Add your own foods with custom calorie values
- **Daily Goal**: Set and track your daily calorie goal
- **Nutrition Summary**: Track protein, carbs, fat, and fiber intake
- **Weekly Overview**: Visual chart showing calorie intake over the past 7 days
- **Date Navigation**: View and edit meals for any date
- **Data Persistence**: All data saved to local storage

## Getting Started

1. Open `index.html` in your web browser
2. Set your daily calorie goal (default is 2000 kcal)
3. Start adding foods to track your meals

## How to Use

### Adding Food from Database
1. Type in the search box to find foods
2. Click on a suggestion to select it
3. Adjust the serving size if needed
4. Select the meal type (Breakfast, Lunch, Dinner, or Snacks)
5. Click "Add Food"

### Adding Custom Food
1. Enter the food name in the "Food name" field
2. Enter calories per 100g
3. Enter serving size in grams
4. Click "Add Food"

### Navigating Dates
- Use the left/right arrows to move between days
- Click the date picker to jump to a specific date
